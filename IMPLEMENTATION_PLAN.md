# BuildSpace implementation

1. Canonical meter-based scene, pure geometry, rich original vector catalog and furnished seven-room sample.
2. Three-pane editor, command history, precision tools and shared-model 2D/3D.
3. PostgreSQL/Prisma API, secure sessions, optimistic concurrency, immutable versions.
4. Materials, floors, analysis, estimates, import/export, project management.
5. Sharing/collaboration, regression and browser visual review.

The requested complete product is the acceptance target. Incomplete capabilities must be named, never presented as finished. See PROGRESS.md.
