# Unfinished requirements and practical limits

The user's full first-product brief remains the target. The following are **unfinished**, not removed from scope. Current tests do not establish complete release acceptance.

## Partial implementations

- Architecture: rectangular/polygon rooms, shared-wall deduplication, room split/union and midpoint wall split work. Free wall drawing does not infer rooms; a complete vertex/half-edge topology solver, collinear merge, arbitrary wall endpoint handles, offsets/joins, curved walls, angle/object/endpoint snapping and automatic junction repair remain incomplete. Length edits move connected room endpoints conservatively; large changes can be rejected when openings would detach.
- Openings: host IDs, offsets, dimensions, single/double/sliding/pocket/bifold 2D door symbols and real 3D voids exist. Door/window frame/style geometry is approximate; bifold leaves, pocket cavities, full 2D export style parity and configurable hardware/materials are incomplete. No exact door-swing collision analysis.
- Floors/stairs: floor add/duplicate/switch/height/elevation and procedural stairs exist. No automatic stairwell holes, linked vertical openings, cross-floor alignment, ceiling slabs/ceiling visibility or floor reordering.
- Furniture: 100 configurations across original procedural families, not 100 distinct photoreal models. Names/prices/dimensions differ, but many variants share the same vector/model family. Richer variant-specific geometry, proper category placement rules, curtains/art and comprehensive custom asset/preset management are incomplete. Group identity/movement exists; group transforms/distribution/marquee/context menus are incomplete. No configurable resize limits per catalog entry.
- Materials: searchable fixed finish presets, room/furniture colors and wood/tile floor textures in both renderers. No editable wall faces, ceiling finishes, custom texture uploads/palettes, texture scale/rotation controls, roughness/metalness/opacity inspector or favorites/recent finishes.
- Lighting: ambient intensity, approximate sun direction/time and working lamp point lights. No independent light entity schema/temperature/intensity/direction/shadow inspector; not all requested fixture classes.
- 3D: physical shared-scene floors/walls/openings and simplified furnishing; orbit, move/rotate gizmos, walkthrough, saved cameras. No certified physical lighting, AO/quality presets, focus-selection, true orthographic camera, optimized instancing or complete material/asset lifecycle management. Top view uses the perspective camera. Walkthrough has no collision physics and desktop pointer lock is the primary input.
- Analysis: polygon validity/overlap, shared-wall layout, proper wall crossings, rotated object SAT overlap/containment, opening constraints and stable issue IDs. Configurable clearance distances, exact door swings, object-wall collisions, broad room-overlap robustness for arbitrary coincident edges and building/accessibility-code checks remain incomplete. Only the first entity in an object overlap is highlighted.
- Estimates: actual furniture prices, polygon flooring and room-facing wall area; CSV and PDF summary. Opening area is not deducted; labor/tax/delivery, editable per-finish unit rates, sorting/filtering by room/floor, estimate snapshot comparisons and certified net/interior area offsets remain incomplete. All prices are demo values.
- Projects/versions: DB CRUD, search, favorites, duplicate/delete, eight populated templates plus blank, acknowledged autosave, retained local drafts, immutable named snapshots and restore. Gallery thumbnails, favorite/recent tabs/sort, version side-by-side comparison/timeline and comprehensive offline reconciliation are unfinished. Numeric field changes and sliders can create more history entries than an ideal batched interaction.
- Collaboration: account permissions, revocable links, presence/cursors, accepted revision propagation, reconnection and conservative CAS conflicts. No semantic operation merge/CRDT, remote selections, cursor-floor filtering or multi-process pub/sub. Two simultaneously dirty clients require explicit resolution or Save a Copy. Immediate broadcast access/session rechecks are implemented, but a full adversarial WebSocket suite is still needed.
- Imports: format-1 JSON; bounded PNG/JPEG tracing with calibration; explicit-unit ASCII DXF LINE/LWPOLYLINE subset. PDF tracing import, GLB/glTF furniture import, texture/asset management and binary DXF/DWG are missing. DXF unsupported entities are reported; bulged polylines are rejected. DXF walls do not automatically become closed rooms.
- Exports: SVG, PNG, scale-to-fit A3 PDF, JSON, CSV, estimate PDF, current Three-scene GLB, and 3D PNG. No configurable page size/orientation/architectural scale or export floor/quality chooser. GLB is decoded before download; it can still include helpers from the rendered scene. Texture/shader support follows Three's exporter. PNG has a white background; transparent export is not implemented.
- Accessibility/responsive: desktop panes, phone drawers, keyboard commands that ignore form fields, modal focus containment and destructive confirmations. Full keyboard-only canvas editing, touch transform/pinch/walkthrough gestures, robust screen-reader scene navigation, all contrast targets and a full device matrix remain incomplete.
- Accounts/security: salted password hashes, secure-session cookies, ownership/roles, revocation, input bounds, same-origin checks and basic local rate limiting. Password reset delivery, profile management, invitations to accounts not yet registered, production abuse defenses, CSP/security headers, audit logging and security review are incomplete. Do not publicly deploy with local guest mode/development credentials.

## Verification limits

The specifically named `references/editor-reference.png` was not supplied on disk. Four attached images were visually inspected; captured editor screenshots were compared qualitatively with their composition. No pixel-difference claim is made.

Browser tests use installed Chromium with software WebGL. They verify real rendering and files, not production GPU performance, photorealism, building compliance, every gizmo gesture or every feature combination. New-task cloud snapshot restoration and publication have not been performed by the agent.
